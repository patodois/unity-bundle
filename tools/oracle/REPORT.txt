Oracle report: unity-bundle against the rabex fork as a black box
==================================================================

Run on 2026-10-25, on the Steam Windows build of Shin Megami Tensei III Nocturne HD Remaster
(2,251 bundles in smt3hd_Data/StreamingAssets/PC, 837 in dlc/*, 9 loose serialized files in
smt3hd_Data), read by memory map, never loading a bundle whole except the main serialized file
of one (the largest is under 700 MB; the program waits for memory budget before reading one).

  oracle GAME --threads 2 --budget-mb 600        (peak resident size 1.8 GB)
  oracle GAME --no-values --threads 3            (with a temporary counter on the common strings)
  oracle GAME --fuzz 400                         (mutated copies of bundles up to 600 KiB)
  oracle GAME --fuzz 100 --fuzz-max-kb 12288 --fuzz-bundles 200

The oracle is rabex 0.2.1 plus the three fixes of the patodois fork, git revision
56dd8a4d8d5048b6ee7664eadc89d98343c66002 of github.com/patodois/RustyAssetBundleEXtractor
(branch `nocturne`), with the features compression-lz4 and compression-lzma. What is compared:

 * the header fields rabex exposes, every block, every directory entry;
 * the whole decompressed stream of each bundle, in 8 MiB pieces, byte for byte;
 * four byte ranges of each file and the first byte past its end, this crate's against rabex's;
 * each file whole, up to 64 MiB;
 * the main serialized file: the bytes, then the header, type table, every type tree node,
   objects, externals, script types, reference types, user information;
 * for every object that has a type tree, a digest of everything `deserialize_any` produces
   (every visit call, with its value, in order) through both libraries;
 * the typed values of the 14 classes nocturne-unpack reads (GameObject, Transform, Material,
   MeshRenderer/SkinnedMeshRenderer, MeshFilter, Mesh, Texture2D, Shader, TextAsset,
   AnimationClip, Avatar, AnimatorController, Animator, AssetBundle), as a hash of their Debug
   output, and the streamed .resS range each texture and mesh names;
 * the class name of every class id met.
